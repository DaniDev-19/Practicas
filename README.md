# 🚀 ReactPro - Portafolio Educativo Frontend

![ReactPro Banner](file:///C:/Users/progr/.gemini/antigravity/brain/f626f2ae-e7b1-471c-9b55-66493acc449a/media__1778812943904.png)

**ReactPro** es un ecosistema interactivo diseñado para el aprendizaje y la demostración de capacidades en el desarrollo frontend moderno. Este proyecto no es solo una colección de prácticas, sino una plataforma educativa completa que combina teoría profunda, documentación técnica y componentes UI premium.

---

## ✨ Características Principales

*   **💎 Estética Premium**: Interfaz basada en *Glassmorphism* con modo oscuro nativo, gradientes vibrantes y micro-animaciones fluidas.
*   **🧩 Arquitectura Modular**: Estructura atómica de componentes, separación clara entre lógica de datos y visualización.
*   **📚 Hub Educativo**: Secciones dedicadas a la teoría de React, documentación de Hooks y métodos esenciales de JavaScript (ES6+).
*   **🛠 UI Kit Propio**: Biblioteca de componentes reutilizables (Botones, Inputs, Modales, Tooltips, Alertas) construidos con CSS Modules.
*   **⚡ Optimización y SEO**: Implementación de buenas prácticas de SEO, carga optimizada y tipado estricto con TypeScript.
*   **📱 Totalmente Responsivo**: Experiencia adaptativa completa, incluyendo un menú lateral dinámico para dispositivos móviles.

---

## 🛠 Tech Stack

*   **Core**: [React 18](https://react.dev/)
*   **Lenguaje**: [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
*   **Tooling**: [Vite](https://vitejs.dev/)
*   **Routing**: [React Router 6](https://reactrouter.com/)
*   **Estilos**: [CSS Modules](https://github.com/css-modules/css-modules) (Vanilla CSS)
*   **Iconos**: [React Icons](https://react-icons.github.io/react-icons/) (Feather & FontAwesome)

## 📂 Estructura del Proyecto

```text
src/
├── assets/         # Recursos estáticos (imágenes, SVGs)
├── components/     # Componentes organizados por dominio
│   ├── home/       # Componentes de la landing page
│   ├── layout/     # Estructura global (Sidebar, Navbar)
│   ├── practicas/  # Lógica de ejercicios (CRUD, TaskManager, etc.)
│   ├── ui/         # Componentes base (Button, Input, Card)
│   └── ...         # Referencia, Teoria, Tips, Ejercicios
├── data/           # Fuente de verdad única para contenidos
├── layout/         # Contenedores principales de la aplicación
├── pages/          # Vistas de alto nivel (Rutas)
├── styles/         # Sistema de diseño global (Core & Variables)
└── App.tsx         # Configuración de rutas y orquestación
```

## 🚀 Instalación y Uso

1.  **Clonar el repositorio**:
    ```bash
    git clone https://github.com/DaniDev-19/Practicas.git
    ```

2.  **Instalar dependencias**:
    ```bash
    npm install
    ```

3.  **Iniciar servidor de desarrollo**:
    ```bash
    npm run dev
    ```

4.  **Construir para producción**:
    ```bash
    npm run build
    ```

## 📖 Módulos Destacados

### 🟢 Teoría y Referencia
Un "Cheat Sheet" interactivo con explicaciones detalladas sobre el ciclo de vida, el Virtual DOM y todos los Hooks oficiales.

### 🔵 Componentes UI
Showcase de componentes construidos desde cero, demostrando el uso de `props`, `children`, `forwardRef` y encapsulamiento de estilos.

### 🟡 Prácticas Reales
Desde un **Gestor de Tareas** con persistencia en `localStorage` hasta **Consumo de APIs** asíncronas con manejo de estados de carga y errores.

### 🔴 Desafíos Lógicos
Mini-juegos y quices técnicos para poner a prueba conocimientos de lógica y React con sistema de puntuación.
